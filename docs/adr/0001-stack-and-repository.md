# ADR-0001: Витрины в Postgres, второй пересчёт на Python, статичный дашборд из выгрузки

Date: 2026-11-19
Status: accepted

## Контекст

Тестовое задание на 3–4 часа: риск-сводка по синтетическому портфелю на стеке заказчика —
PostgreSQL, семантическая модель в их YAML-формате, дашборд на Vega-Lite через vega-embed.
Проверяющий должен поднять всё одной командой, а каждая цифра — сходиться с источником. В данных
есть подвохи: полные дубли, списанные кредиты, валютные кредиты, граничные значения просрочки.

## Решение

**PostgreSQL 16 в Docker, `psql` внутри контейнера.** На хосте не нужно ничего, кроме Docker; порт
не публикуется, поэтому нет конфликта с локальным Postgres.

**Сырой слой в `text`, типы — в витринах.** Загрузка CSV не падает на кривом значении, а ошибка
приведения видна в конкретной витрине (`sql/10_reporting.sql:reporting.v_loans_clean`).

**Вторая реализация метрик — `scripts/verify.py` на стандартной библиотеке Python.** Проверки внутри
SQL не ловят ошибку толкования, которая есть и в проверке, и в витрине. Пересчёт другим способом
по исходным CSV её ловит.

**Дашборд читает JSON-выгрузку витрин** (`scripts/export.sh`). Страница статичная, без бэкенда;
спеки остаются отдельными файлами с `data.url`.

**`Makefile` — единственная точка входа** для человека, агента и проверяющего.

Отвергнуто:

- **`psql` на хосте и публикация порта 5432.** Лишняя зависимость у проверяющего и конфликт с
  его локальным Postgres.
- **pandas для пересчёта.** Нужен venv; стандартной библиотеки и `Decimal` хватает.
- **Курс ближайшего прошлого дня, если на дату среза курса нет.** Скрывает дыру в данных; задание
  требует курс на дату среза.
- **Данные внутри спек (`data.values`).** Спеки перестали бы быть конфигом и менялись бы при
  каждой перезагрузке данных.

## Последствия

**Правка определения — в двух местах.** `sql/10_reporting.sql` и `scripts/verify.py` меняются
вместе, иначе `make check` красный. Это намеренно.

**`dashboard/data/*.json` лежат в git.** Дашборд открывается без базы, но после правки витрин
выгрузку нужно перегенерировать (`make export`).

**Дашборду нужен интернет.** Vega берётся с jsDelivr. Если понадобится офлайн — библиотеки
кладутся в репозиторий.
